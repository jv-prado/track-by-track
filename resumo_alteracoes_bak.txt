RESUMO DAS ALTERAÇÕES PARA CORRIGIR O PROBLEMA DE PERSISTÊNCIA DE AUTENTICAÇÃO:

1. Implementamos a configuração de persistência em todos os métodos de autenticação (login, login com Google, cadastro)
2. Criamos um arquivo de inicialização separado para o Firebase para garantir que a persistência seja configurada corretamente
3. Adicionamos funções de diagnóstico para ajudar a identificar problemas com a autenticação
4. Melhoramos o AuthContext para verificar e registrar o estado de autenticação
5. Adicionamos verificações de autenticação no carregamento da aplicação e na tela de login
6. Aplicamos a configuração de persistência browserLocalPersistence, que mantém o usuário logado mesmo após fechar o navegador

ARQUIVOS CRIADOS OU MODIFICADOS:
- src/services/firebase/index.js (modificado para adicionar persistência em todas as funções de autenticação)
- src/services/firebase/auth-helper.js (novo arquivo para auxiliar na verificação de autenticação)
- src/services/firebase/init.js (novo arquivo para garantir inicialização correta do Firebase)
- src/services/debug.js (novo arquivo para auxiliar no diagnóstico de problemas)
- src/contexts/AuthContext.jsx (modificado para melhorar verificação de autenticação)
- src/componentes/AuthForms/Login.jsx (modificado para adicionar verificações adicionais)
- src/App.tsx (modificado para adicionar verificação de autenticação persistente)
- src/main.tsx (modificado para garantir inicialização correta do Firebase)
